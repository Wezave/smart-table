# Проект приложение покупок
Приложение для просмотра сделок на основании различных датасетов.

## Описание проекта
Сайт, отображающий таблицу с информацией о дате покупки, покупателях, продавцах и суммам сделки. По каждому столбцу реализована фильтрация и поиск, а также глобальный поиск по всем столбцам

## Структура проекта
1. `index.html` — главная страница, позиционирования элементов
2. `src/style.css` — стили страниц и переменные
3. `src/fonts/*.css` — шрифты, используемые на сайте
4. `src/*.js` — основная логика программы (подргузка и связь блоков)
5. `src/components/*.js` — методы работы программы
6. `src/lib/*.js` — поиск, сравнения для массивов данных
7. `dataset_..js` — вариации входных данных для наполнения
